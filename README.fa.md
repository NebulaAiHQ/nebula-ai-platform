## 🌌 Nebula AI Platform چیست؟

**Nebula AI Platform** یک اکوسیستم کامل و سلف‌هاست است که به **هر کسی — حتی افرادی که هیچ دانش برنامه‌نویسی ندارند** — اجازه می‌دهد یک ربات تلگرام حرفه‌ای و اتوماسیون‌شده اجرا کند و آن را از یک پنل وب زیبا به **۷ زبان** مدیریت کند.

شما حتی یک خط کد نمی‌نویسید. تنها **یک دستور** روی یک سرور تازه اجرا می‌کنید، توکن ربات تلگرام‌تان را وصل می‌کنید و همه‌چیز آماده است: ربات، دیتابیس، پنل مدیریت، سیستم پرداخت، فروشگاه و بیشتر — همه به‌صورت خودکار داخل یک کانتینر داکر دربسته راه‌اندازی می‌شوند.

ربات **۲۴ ساعته و بدون قطعی** کار می‌کند، با یک **معماری قدرتمند و امن‌سازی‌شده** که برای پایداری طراحی شده. چه از قبل یک **پنل VPN سنایی / هیدیفای / 3x-ui** دارید و چه از صفر شروع می‌کنید، Nebula از طریق **اتوماسیون** به آن وصل می‌شود و آن را به یک سرویس تلگرام کامل و درآمدزا تبدیل می‌کند — با اشتراک، پرداخت کریپتو، فروشگاه دیجیتال، سیستم دعوت، مأموریت‌ها، ابزار ضدتقلب و خیلی بیشتر.

## 🏗️ معماری

Nebula به‌صورت یک **ایمیج داکر دربسته‌ی واحد** منتشر می‌شود تا نصب شما تکرارپذیر باشد و کد منبع محفوظ بماند. نصب‌کننده همه‌چیز را خودکار راه‌اندازی می‌کند:

- 🐳 **کانتینر داکر** — اپلیکیشن Node.js (پنل مدیریت + ربات) را با ری‌استارت خودکار اجرا می‌کند
- 🗄️ **دیتابیس SQLite** — کاربران، مأموریت‌ها، لایسنس‌ها، سفارش‌ها، تنظیمات؛ روی یک **volume ماندگار** که با آپدیت پاک نمی‌شود
- 🔒 **Nginx + گواهی SSL لتس‌انکریپت** — HTTPS اختیاری با یک دستور برای دامنه یا IP خام
- 🤖 **موتور ربات تلگرام** (grammY) — long-polling، همیشه‌روشن، مقاوم
- ⌨️ **دستور `nebula`** — مدیریت همه‌چیز از ترمینال (start، stop، update، logs، ssl، password)
- 🔑 **لایسنس Ed25519** — تأیید نامتقارن و ضدجعل لایسنس

این معماری برای **پایداری بدون قطعی** و **امنیت در سطح سازمانی** ساخته شده — بدون کد منبع افشا‌شده، لایسنس امضاشده، ایمیج دربسته و پشتیبان‌گیری خودکار.

## 🛠 دستورات مدیریت

| Command | What it does |
|---|---|
| `nebula` | Open the graphical management menu |
| `nebula start` / `stop` / `restart` | Start / stop / restart the platform |
| `nebula status` | Service status, version, panel URL (+ HTTPS) |
| `nebula logs` | Follow live logs |
| `nebula update` | Update to the newest version (data kept) |
| `nebula ssl <domain>` | Free HTTPS for a domain |
| `nebula ssl auto` | Free HTTPS on the server IP (no domain) |
| `nebula password` | Show the panel password |
| `nebula uninstall` | Remove everything |
